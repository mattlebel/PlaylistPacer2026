# Strava brand assets

Strava requires its official, unmodified assets. Download the button and logo packs from
https://developers.strava.com/guidelines/ and save these two files here:

| File in this folder              | Official asset to use                                   |
| -------------------------------- | ------------------------------------------------------- |
| `connect-with-strava.svg`        | "Connect with Strava" button, orange, SVG               |
| `powered-by-strava-white.svg`    | "Powered by Strava" logo, white, horizontal, SVG        |

Rename them to match exactly. Until they're here, the app shows plain-text stand-ins.
